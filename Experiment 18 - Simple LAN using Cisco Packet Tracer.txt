AIM:
To design and build a simple Local Area Network (LAN) in Cisco Packet Tracer by connecting end devices through a switch, assigning IP addresses, and verifying end-to-end connectivity with the ping command.

SOFTWARE REQUIRED:
- Computer running Windows.
- Cisco Packet Tracer (version 8.x recommended).
- Basic knowledge of IPv4 addressing and subnet masks.

THEORY:
Cisco Packet Tracer is a network simulation tool used to build and test networks without physical hardware. A simple LAN connects end devices to a central switch. A switch forwards frames using MAC addresses. Devices in the same IP subnet can communicate directly through the switch.

TOPOLOGY:
Connect three PCs to one 2960 switch using Copper Straight-Through cables.

ADDRESSING PLAN:
| Device | Interface | IP address | Subnet mask |
|---|---|---|---|
| PC0 | FastEthernet0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | FastEthernet0 | 192.168.1.2 | 255.255.255.0 |
| PC2 | FastEthernet0 | 192.168.1.3 | 255.255.255.0 |

PROCEDURE (WINDOWS):
1. Open Cisco Packet Tracer and create a new project.
2. From Network Devices > Switches, select a 2960 switch and place it in the logical workspace.
3. From End Devices, place three PCs (PC0, PC1, and PC2).
4. Select Connections (lightning-bolt icon), choose Copper Straight-Through, and connect each PC's FastEthernet0 port to a free FastEthernet port on the switch.
5. Wait until the link indicators turn green.
6. Open PC0 > Desktop > IP Configuration. Select Static and enter IP address 192.168.1.1 and subnet mask 255.255.255.0.
7. Configure PC1 as 192.168.1.2 and PC2 as 192.168.1.3, using the same subnet mask.
8. On PC0, open Desktop > Command Prompt and run:
   ```text
   ping 192.168.1.2
   ping 192.168.1.3
   ```
9. Repeat ping tests from other PCs to verify connectivity between all devices.
10. Optionally switch to Simulation mode and run ping again to observe ICMP packets moving through the switch.
11. Save the project using File > Save As with a .pkt extension.

RESULT:
Thus, a simple LAN of three PCs connected through a 2960 switch was built in Cisco Packet Tracer. IP addresses were assigned in the 192.168.1.0/24 network, and end-to-end connectivity was verified using ping.
