AIM:
To learn network commands and capture ping and route-tracing packets using a network protocol analyser.

SOFTWARE REQUIRED:
- Windows 10/11 computer with an active network connection.
- Command Prompt or PowerShell.
- Wireshark with Npcap, or Windows Packet Monitor (Pktmon).
- Administrator privileges for packet capture.

WINDOWS COMMAND REFERENCE:
| Purpose | Windows command |
|---|---|
| View IP configuration | `ipconfig` / `ipconfig /all` |
| Active connections and listening ports | `netstat -ano` |
| Routing table | `route print` or `netstat -r` |
| DNS lookup | `nslookup www.google.com` |
| Trace route | `tracert www.google.com` |
| Test connectivity | `ping -n 4 www.google.com` |
| Hostname | `hostname` |
| Adapter MAC addresses | `getmac /v` |
| ARP cache | `arp -a` |
| Running processes | `tasklist` |

LINUX COMMAND EQUIVALENTS:
`ip addr`, `ip route`, `ss -ano`, `nslookup`, `traceroute`, `ping`, `hostname`, `ip link`, `ip neigh`, and `ps` are common equivalents. `tcpdump` is available on Linux; on Windows use Wireshark/Npcap or Pktmon instead.

PROCEDURE (WINDOWS):
1. Open Command Prompt. Run `ipconfig /all` and note the IPv4 address, subnet mask, default gateway, DNS server, and physical address.
2. Run `netstat -ano` to inspect active TCP/UDP endpoints and process IDs. Use `tasklist /fi "PID eq <number>"` to map a PID to a process.
3. Run `nslookup www.google.com` to view DNS resolution.
4. Run `tracert www.google.com` to inspect the route and hop response times.
5. Run `ping -n 4 www.google.com` and note replies, round-trip times, and packet loss.
6. Run `getmac /v` and `arp -a` to inspect MAC addresses and the ARP cache.
7. Launch Wireshark as administrator, select the active Wi-Fi/Ethernet interface, and start capture before running ping/tracert.
8. Apply `icmp` as a display filter to inspect ping packets. Inspect Echo Request and Echo Reply details.
9. Stop the capture and save it as `.pcapng` if required.

WINDOWS PKTMON ALTERNATIVE:
Run Command Prompt as Administrator:
```bat
pktmon start --capture --pkt-size 0
ping -n 4 8.8.8.8
pktmon stop
pktmon etl2pcap PktMon.etl --out packetcapture.pcapng
```
Open `packetcapture.pcapng` in Wireshark. Options can vary by Windows build; `pktmon help` shows supported syntax.

RESULT:
Thus, common network commands were executed, and ping/route-tracing packets were captured and examined using a network protocol analyser.
